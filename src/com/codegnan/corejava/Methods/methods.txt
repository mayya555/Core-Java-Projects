Call by Reference or Pass by Reference:
--------------------------------------
Passby reference means the actual memory address(reference) of the variable is 
passed to the method.
The called method works on the original variable.
A copy of the object reference is sent to the method.



We say that Java supports only pass by value.


- Java is called pass by value because it always passes a copy of the argument
  to a method.
It will never pass the original variable.


Even when an object reference is passed, java passes a copy of the object
reference,
It will not pass the original object reference.


Therefore we can say that java only pass by value and not passby reference.
