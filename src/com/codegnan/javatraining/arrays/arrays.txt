Single Dimension Array:
-----------------------

An array whose elements can be accessed with a single index is known as 
Single dimensional array.

Eg:
String[] countryNames= {"India","US","Australia"};

//Now , the elements in countryNames array can be accessed using single index as below:

countryNames[0] //India
countryNames[1] //"US"
countryNames[2] //"Australia"


Multidimensional Array:
======================
A multidimensionl array is an Array of Arrays.
It stores data in two or more dimesions.
Each element in mutlidimensional arrays are accessed with mutliple indices.


Multidimensionl array creation syntax:
1.datatype arrayName[][] = new datatype[rows][columns];

The above is a 2 dimensional array.
It must be declared by specifying the numeber of rows and columns for the array 

eg:

int marks[][] = new int[2][3];
In the above example, int[2][3] means,
 2 rows in an array , with 3 columns in each row.
 

In a 2 dimensional array , arrayName.length will return the 
number of rows of an array.

eg. sMarks.length will return the number of rows in sMarks array.

arrayName[i].length will give the number of columns in eah row.
where i is the row index.


To work with a 2 dimensional array , we need two for loops.
- outer for loop and an inner for loop.
Outer for loop represents the rows of an array
and inner for loop represents the columns in a particular row.




RaggedArray or Zagged Array:
---------------------------
A ragged array also known as Zagged Array is an array with different number of columns 
in each row.

To create a Ragged Array,we can use the inline Array creation approach or normal 
declaration with new keyword.

Zagged Array creation with new keyword syntax:
-----------------------------------------------
datatype[][] arrayname = new datatype[size][];

Since the number of columns are not constant and as they vary for each row,
we do not specify the column size while declaring the array.



ArrayIndexOutOfBoundsException:
--------------------------------
An exception is nothing but an abnormal condition.
when an abnormal condition occurs in the program the JVM terminates the program.


ArrayIndexOutOfBoundsException is a Runtime exception that is thrown by Virtual machine when you 
try to insert the element with an index more than the specified size.
